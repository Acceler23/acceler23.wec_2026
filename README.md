_____________THEME OPTIONS_____________

1 Table Page
    Cicles Between pages of all the renders 

2 WEC Mode
    1 WEC Colors
        Replaces Teams/Cars colors with FIAWEC colors
    2 WEC Logotypes
        Replaces Teams/Cars logotypes with FIAWEC logotypes
    3 WEC Event name
        Replaces the Full Name of the track with FIAWEC Event Names

3 Drivers
    1 Driver Name
        Choose the way the Name of the Drivers are shown
    2 Car Number as
        Choose the way the Race Number of the Car are shown

4 Global Options
    1 Card Track Name Size
        Font Size for the Track Name that appears on the left side
